# News Classification with TF-IDF & SVM
## A Novel Text Mining Approach Based on TF-IDF and Support Vector Machine for News Classification

This project implements a **text classification pipeline** inspired by the research paper:  
**"A Novel Text Mining Approach Based on TF-IDF and Support Vector Machine for News Classification."**

The system applies a traditional **Natural Language Processing (NLP)** workflow to classify **BBC news articles** into five categories using:
- Text preprocessing  
- Feature extraction with **TF-IDF**  
- Classification using **Support Vector Machine (SVM)**  

---

## 📂 Dataset

The project uses the **BBC News Dataset**, which contains **2,225 articles** labeled into **five categories**.  
(The dataset is available on Kaggle. The original paper used both BBC and 20 Newsgroups datasets, but only BBC was used here due to availability.)

Categories:
- Business  
- Entertainment  
- Politics  
- Sport  
- Tech
